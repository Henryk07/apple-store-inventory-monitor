# 果到雷达 · 美加阿版 v2.0.0-us.1

这是 **Henryk07** 维护的 fork 的第一个版本。本 fork 来自 [yuanruoyu515 的美加阿版](https://github.com/yuanruoyu515/apple-store-inventory-monitor)，基于 suversal 上游 **v1.0.26**。一个 macOS 安装包支持美国、加拿大和阿联酋。

## 新增：美国站 Apple HomeView

- 品类里新增 **Home**，可以监控 2026-11-13 上市的 Apple HomeView。只有地区选 United States 时才显示。
- 共 6 个美国 `LL/A` 料号：
  - 桌面版：Silver `MDH14LL/A`、Starlight `MDH34LL/A`、Rose Pink `MDH44LL/A`、Space Gray `MDH24LL/A`
  - 壁挂版：Silver `MDV64LL/A`、Space Gray `MDV74LL/A`
- 「刷新型号」也会抓取 HomeView 的购买页。

## 修复

- **HomeView 被误报无货**：美国站的取货查询不再带 `pl=true`。带着这个参数时，Apple 会把 HomeView 一律回成 `ineligible`。iPhone 的取货状态实测不受影响，只是不可取货时的文案从「Currently unavailable」变成「Unavailable for Pickup」。
- **`ships-to-store` 被误报为接口异常**：Apple 返回 `ships-to-store`（门店现在没有，下单后寄到店再取）时，现在显示为无货，并保留 Apple 给的到店日期。门店真正返回可取货时才会提醒。
- 品类下拉只列出所选地区确实有商品的品类，加拿大和阿联酋不会出现空的 Home。

## 其他变化

- 维护者改为 [Henryk07](https://github.com/Henryk07)。App 顶部的 GitHub 按钮和「下载更新」都指向本 fork，原维护者的 Threads 按钮已移除，「上游源码」入口保留。
- App 副标题改为「iPhone 与 HomeView 库存监控」。
- 版本号从 1.0.28 升到 **2.0.0**。

## 下载与升级

下载 **`Apple-Store-Inventory-Monitor-US-macOS-universal-2.0.0.dmg`**，Apple Silicon 和 Intel Mac 用同一个安装包。

先从菜单栏完全退出旧版，打开 DMG，把 App 拖到 Applications 并替换同名应用，再从「应用程序」打开。Mac 上需要装有 Chrome 或 Edge，监控时保持 Mac 唤醒。文件名、Bundle ID 和配置目录都没变，从 v1.0.28 覆盖升级会保留原来的监控、Bark、声音和查询间隔设置。

本版使用 ad-hoc 签名，没有 Developer ID 证书，也没有经过 Apple 公证。首次打开如果被 macOS 拦截，请先确认安装包来自本仓库、SHA-256 一致，再按 [README 的安装说明](https://github.com/Henryk07/apple-store-inventory-monitor#拖过去就装好了)处理。
